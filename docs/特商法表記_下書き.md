入力場所: **設定 → ポリシー → 法的通知（Legal notice）**

`（　）` は埋めること。`[要確認]` は未確定事項（`docs/未確定事項.md`）。

## 注意

- 販売業者は **tr合同会社**（法人。登記された商号）、所在地も自社のものを開示するため、
  氏名・住所については特商法の要件を満たしている
- **電話番号のみ、受託業者（株式会社アルヒノ）のものを記載する。**
  販売業者名と所在地は自社のものを開示しているため、当初懸念していた論点は
  大きく解消している。残るのは電話番号がtr合同会社自身のものでない点のみ。

  安全側に倒すなら、tr合同会社の電話番号も併記したうえで、
  問い合わせ窓口としてアルヒノを案内する形にする。
- **送料・返品条件は `docs/ページ下書き.md` のFAQと必ず揃えること。**
  両者で食い違うと消費者保護の観点で問題になる

## 支払時期の書き方（参考）

Shopify が自動で決めるものではなく、**どの決済手段を有効にするかで文面が決まる**。
今回は **Shopify ペイメント（クレジットカード）** を採用したため上記の文面にしている。
他の手段を追加した場合は以下を参考に追記すること。

| 決済手段 | 記載例 |
|---|---|
| クレジットカード | ご注文時にお支払いが確定します。実際のご請求日は、ご利用のカード会社の締め日・支払日によります。 |
| コンビニ決済・銀行振込 | ご注文後◯日以内にお支払いください。期限内にご入金が確認できない場合、ご注文をキャンセルさせていただきます。 |
| 代金引換 | 商品お受け取り時に配送業者へお支払いください。 |
| 後払い | 商品発送後に請求書を送付します。記載の期限までにお支払いください。 |

クレジットカードのみなら1行で済む。

## 返品特約について

**「返品についての特約事項」を表示しておくことには意味がある。**
特定商取引法では、通信販売に返品特約の表示がない場合、
商品到着後8日間は送料購入者負担で返品できる法定の返品権が適用される。
特約を明示していれば、その内容が優先される。

今回は「商品に欠陥がある場合を除き、返品には応じません」を表示するため、
**お客様都合の返品には応じない旨が有効になる。**
FAQ（`docs/ページ下書き.md`）にも同じ内容を記載し、食い違わせないこと。
