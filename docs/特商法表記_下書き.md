# 特定商取引法に基づく表記（下書き）

入力場所: **設定 → ポリシー → 法的通知（Legal notice）**
ページとして作るのではない。フッターへのリンク表示はテーマ側で有効化済み。

`（　）` は埋めること。`[要確認]` は未確定事項（`docs/未確定事項.md`）。

---

## 貼り付け用テキスト

```
■ 販売業者
（らんぜ側の正式名称）
※法人の場合は登記された商号、個人事業主の場合は戸籍上の氏名または商業登記された商号。
　屋号のみの表示は認められない（消費者庁 通信販売広告Q&A Q16）。

■ 運営統括責任者
（氏名）

■ 所在地
（郵便番号・住所）

■ お問い合わせ窓口
株式会社（A）
電話番号：03-XXXX-XXXX
受付時間：[要確認：平日◯:◯◯〜◯:◯◯]
メールアドレス：[要確認]

※株式会社（A）は、（販売業者名）より本オンラインショップの
　カスタマーサポート業務を受託しています。

■ 販売価格
各商品ページに税込価格で表示しています。

■ 商品代金以外に必要な費用
送料：全国一律 1,500円（税込）
[要確認：地域別料金へ移行する場合は要修正]
振込手数料等が発生する場合は、お客様のご負担となります。

■ 支払方法
[要確認：クレジットカード、その他決済手段]

■ 支払時期
[要確認：ご注文時に決済が完了します 等]

■ 商品の引渡時期
ご注文確認後、[要確認：◯営業日]以内に発送いたします。
配送状況により、お届けまでにお時間をいただく場合がございます。

■ 返品・交換について
不良品または誤配送の場合、商品到着後[要確認：◯日]以内にご連絡ください。
送料当店負担にて交換または返金いたします。

お客様都合による返品・交換は[要確認：可否と条件]。
```

---

## 注意

- **販売業者名に屋号のみを書かないこと。** Shopifyペイメントの要件でもあり、
  不備があると決済が止まる可能性がある
- **電話番号は受託業者（株式会社A）のもののみを記載する方針。**
  特商法11条が求めるのは販売業者の電話番号で、受託業者の番号のみで足りるかは
  消費者庁のQ&Aに明示がない。依頼により当該構成を採用している
- **送料・返品条件は `docs/ページ下書き.md` のFAQと必ず揃えること。**
  両者で食い違うと消費者保護の観点で問題になる
