# 後から差し替えるもの

以下は初期実装を止めず、管理画面から後で差し替えられる前提で進めてください。

- 最終の商品ラインナップ
- キャップ以外の商品ごとの正式画像
- 商品名 / 販売価格
- サイズ / カラー / 在庫
- 素材 / 寸法 / 商品説明
- 送料ルール
- 返品交換ポリシー
- 特商法 / プライバシー等の正式文言
- Instagram / TikTok / YouTube / X等の正式リンク

## 本番で使用禁止
- モックに存在する架空商品/生成商品画像
- AIで再生成した衣服/バッグ/キャップ/小物

レイアウト確認用のモックと本番アセットが衝突した場合、**本番アセット/このFINAL仕様を優先**してください。
