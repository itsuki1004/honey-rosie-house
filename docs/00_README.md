## 最重要ルール
- **スマホファースト**。
- TOPの構成・余白感・情報量は `01_モック/00_TOP_LAYOUT_REFERENCE_ONLY.jpg` を基準にする。
- モックは**レイアウト参考のみ**。モック内の架空/ダミー商品画像は本番で使用しない。
- **商品・衣服・キャップ・グッズは実物写真のみ**。AIで形・色・ロゴ・文字を描き直さない。
- 商品名、価格、NEW/LIMITED、APPAREL/GOODS、ボタン等は画像に焼き込まずHTML/CSSで実装。
- CATEGORYは **APPAREL / GOODS の2分類のみ**。CAPを独立カテゴリにしない。
- HERO内のCTAボタンは不要。
- 「NEWS」は使わず「新着」。
- 「VIEW ALL」は使わず「すべて見る」。各セクションの**下部中央**に配置。
- 問い合わせ導線は目立たせない。
- 下層ページは最低限。TOPと購入導線、DAILYの見やすさを優先。

## フォルダ
- `01_モック/`：TOPのレイアウト参考。商品写真は参考にしない。
- `02_実装用画像/`：本番で使える実写/支給画像。
- `03_商品データ/`：商品登録用の暫定シート。最終値は差し替え予定。
- `04_実装仕様/`：固定仕様、ページ構成、画像対応表、チェックリスト、未確定事項。
- `05_参考/`：下層のレイアウト参考。完全再現不要。
