# 固定仕様｜ここは変更しない

## サイト方針
- Shopify前提
- モバイルファースト
- 初期リリースはシンプルに。機能追加より世界観と購入しやすさを優先
- Shopify Online Store 2.0相当のセクション編集性を持たせる
- 外部アプリは必須でない限り増やさない

## TOP順序
1. ヘッダー
2. HERO
3. PICKUP
4. CATEGORY（APPAREL / GOODS）
5. 新着
6. DAILY
7. ABOUT
8. SHOPPING GUIDE / FAQ
9. フッター

## UI決定
- HERO CTA：なし
- CATEGORY：APPAREL / GOODSのみ
- 商品カード：スマホ2列
- 横並び：原則2〜3個まで
- 「すべて見る」：各セクション下部中央
- 「NEWS」表記：使用しない
- 「VIEW ALL」表記：使用しない
- 問い合わせ：目立たせない
- 商品/衣服/グッズのAI生成：禁止
- 下層：作り込みすぎない
