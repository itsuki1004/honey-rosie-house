# 実装メモ

仕様の正: `docs/00_README.md` / `docs/固定仕様.md` / `docs/実装仕様.md`
方針: **Dawn 16.0.0 をほぼそのまま使い、セクション順序と構成要素のみ仕様に合わせる。**
カスタムセクションは作らない。

## 1. このブランチで変更した点

### templates/index.json
セクション順序は変更前から仕様どおり（HERO→PICKUP→CATEGORY→新着→DAILY→ABOUT→GUIDE）だったため、
構成要素のみ修正した。

| セクション | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| DAILY | `multicolumn`（手動3列・英語ダミー文） | `featured-blog`（blog: daily / 4件 / 2列） | 実装仕様「Blog最新記事から取得」「最新4件程度」 |
| ABOUT | `rich-text`（文章のみ・英語ダミー） | `image-with-text`（実写1枚＋日本語短文） | 実装仕様「実写1枚 + 短い文章」 |
| GUIDE | 4行目に未設定の `Collapsible row` | 削除し3項目に | 固定仕様「3項目のシンプルな導線」 |

あわせてセクションIDを実体に合わせて改名した（`multicolumn_YCmqiM` → `daily` など）。
テーマエディタ上の見え方は変わらない。

### コレクション参照
固定仕様の「Collections: ALL ITEMS / APPAREL / GOODS」「CAP独立カテゴリは作らない」に合わせ、
参照ハンドルを変更した。**対応するコレクションを管理画面で作る必要がある**（下記 2-1）。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| PICKUP | `オリジナルキャップ` | `pick-up` |
| CATEGORY 1枚目 | `frontpage` | `apparel` |
| CATEGORY 2枚目 | `オリジナルトートバッグ` | `goods` |
| 新着 | `frontpage` | `all-items` |

### locales/ja.json
| キー | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| `products.product.add_to_cart` | カートに追加する | カートに入れる | モック準拠 |
| `sections.featured_collection.view_all` | すべてを表示する | すべて見る | 固定仕様「VIEW ALL表記は使用しない」 |
| `sections.featured_blog.view_all` | 同上 | すべて見る | 同上 |
| `sections.collection_list.view_all` | 同上 | すべて見る | 同上 |

### docs/images/
支給された本番画像を格納。**Shopify の 設定→ファイル にアップロードして各セクションで選択する。**
テーマの `assets/` には置いていない（Dawn標準セクションは image_picker = Files 参照のため）。

HERO 画像は既に Files へアップ済みで index.json から参照されている。

## 6. ダミー商品の非表示化（Dawn標準の挙動を変更）

Dawn は、コレクションに商品が無い場合・ブログに記事が無い場合に、
オンボーディング用のダミー商品／ダミー記事を描画する。
本番ストアでは登録予定のない商品が並んで見えるため、以下を変更した。

| ファイル | 変更内容 |
|---|---|
| `sections/featured-collection.liquid` | コレクションが未設定、または商品0件のときセクションごと出力しない |
| `sections/collection-list.liquid` | 存在しないコレクションを指すブロックをスキップ |
| `sections/featured-blog.liquid` | ブログが未設定、または記事0件のときセクションごと出力しない |

**副作用: コレクション/ブログが未作成のあいだ、該当セクションはTOPから消える。**
PICKUP / CATEGORY / 新着 / DAILY を表示するには「2-1. コレクション作成」「2-2. ブログ作成」が必須。

いずれも Dawn 本体への差分なので、Dawn をバージョンアップする際は再適用が必要。
該当箇所には `HONEY ROSIE HOUSE 追加:` のコメントを入れてある。

## 7. テーマ設定の変更

| 対象 | 設定 | 変更 | 理由 |
|---|---|---|---|
| フッター | `newsletter_enable` | true → **false** | 固定仕様・モックに無い |
| フッター | `enable_follow_on_shop` | true → **false** | 同上 |
| フッター | `enable_country_selector` / `enable_language_selector` | true → **false** | 日本向け単一ストア |
| フッター | ブロック | `link_list`（menu: `footer`）を追加 | モックのフッター導線。メニュー項目は管理画面の「フッターメニュー」で編集 |
| ヘッダー | `enable_country_selector` / `enable_language_selector` | true → **false** | 同上 |
| テーマ設定 | `social_instagram_link` | 未設定 → `https://www.instagram.com/honey.rosie.house/` | 公式アカウント |

Instagram 以外のSNSリンクは未設定のまま（`docs/未確定事項.md`）。
プライバシー等のポリシーリンクはフッターの `show_policy: true` により自動表示されるため、
Shopify のポリシー設定を埋める必要がある。

## 8. TOP構成の変更（指示による）

### SHOPPING GUIDE / FAQ セクションを TOP から削除
`docs/固定仕様.md` の TOP順序では 8番目に置く想定だったが、依頼により TOP からは外した。
現在の TOP順序は HERO → PICKUP → CATEGORY → 新着 → DAILY → ABOUT。

`shopping-guide` ページ自体は `docs/固定仕様.md`「初期ページ」に残っているため、
**フッターメニューからの導線は必要**。

### ABOUT 画像
`docs/images/about.jpg` を使用する。
`image-with-text` の画像は image_picker（Shopify Files 参照）のため、
**管理画面で「設定 → ファイル」にアップロードし、テーマエディタの ABOUT セクションで選択する必要がある。**
リポジトリからは設定できない。

### 新着セクションを一旦非表示
`templates/index.json` の `new_arrivals` に `"disabled": true` を設定。
削除ではないため、テーマエディタのセクション一覧から目のアイコンで再表示できる。
再表示する際は `all-items` コレクション（並び順=新しい順）が必要。

### アナウンスバーを削除
`sections/header-group.json` から `announcement-bar` セクションを削除（「NEW ONLINE SHOP」の帯）。
再度使う場合はテーマエディタの「セクションを追加」から戻せる。
