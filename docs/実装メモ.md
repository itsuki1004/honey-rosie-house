# 実装メモ

仕様の正: `docs/00_README.md` / `docs/固定仕様.md` / `docs/実装仕様.md`
方針: **Dawn 16.0.0 をほぼそのまま使い、セクション順序と構成要素のみ仕様に合わせる。**
カスタムセクションは作らない。

## 1. このブランチで変更した点

### templates/index.json
セクション順序は変更前から仕様どおり（HERO→PICKUP→CATEGORY→新着→DAILY→ABOUT→GUIDE）だったため、
構成要素のみ修正した。

| セクション | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| DAILY | `multicolumn`（手動3列・英語ダミー文） | `featured-blog`（blog: daily / 4件 / 2列） | 実装仕様「Blog最新記事から取得」「最新4件程度」 |
| ABOUT | `rich-text`（文章のみ・英語ダミー） | `image-with-text`（実写1枚＋日本語短文） | 実装仕様「実写1枚 + 短い文章」 |
| GUIDE | 4行目に未設定の `Collapsible row` | 削除し3項目に | 固定仕様「3項目のシンプルな導線」 |

あわせてセクションIDを実体に合わせて改名した（`multicolumn_YCmqiM` → `daily` など）。
テーマエディタ上の見え方は変わらない。

### コレクション参照
固定仕様の「Collections: ALL ITEMS / APPAREL / GOODS」「CAP独立カテゴリは作らない」に合わせ、
参照ハンドルを変更した。**対応するコレクションを管理画面で作る必要がある**（下記 2-1）。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| PICKUP | `オリジナルキャップ` | `pickup` |
| CATEGORY 1枚目 | `frontpage` | `apparel` |
| CATEGORY 2枚目 | `オリジナルトートバッグ` | `goods` |
| 新着 | `frontpage` | `all-items` |

### locales/ja.json
| キー | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| `products.product.add_to_cart` | カートに追加する | カートに入れる | モック準拠 |
| `sections.featured_collection.view_all` | すべてを表示する | すべて見る | 固定仕様「VIEW ALL表記は使用しない」 |
| `sections.featured_blog.view_all` | 同上 | すべて見る | 同上 |
| `sections.collection_list.view_all` | 同上 | すべて見る | 同上 |

### docs/images/
支給された本番画像を格納。**Shopify の 設定→ファイル にアップロードして各セクションで選択する。**
テーマの `assets/` には置いていない（Dawn標準セクションは image_picker = Files 参照のため）。

HERO 画像は既に Files へアップ済みで index.json から参照されている。

## 2. 管理画面で必要な作業

### 2-1. コレクション作成
| ハンドル | 名前 | 種類 | 中身 |
|---|---|---|---|
| `all-items` | ALL ITEMS | 自動 | 全商品。並び順=**新しい順**（新着セクションで使用） |
| `apparel` | APPAREL | 手動/自動 | キャップ等の衣類 |
| `goods` | GOODS | 手動/自動 | トートバッグ・缶バッジ等 |
| `pickup` | PICKUP | 手動 | TOPに出す2〜4商品 |

※ 既存の `オリジナルキャップ` `オリジナルトートバッグ` コレクションは、
固定仕様の「CAP独立カテゴリは作らない」に反するためカテゴリ導線には使わない。

### 2-2. ブログ作成
- ハンドル `daily` / タイトル `DAILY`
- Dawn 初期の `news` ブログとは別に作るか、`news` を DAILY にリネームする

### 2-3. ページ作成
- `about`（ABOUT）
- `shopping-guide`（SHOPPING GUIDE / FAQ、アコーディオンは GUIDE セクション側で持つ）

### 2-4. 画像アップロード（設定→ファイル）
| 用途 | ファイル |
|---|---|
| CATEGORY APPAREL | `docs/images/category-apparel.jpg` |
| CATEGORY GOODS | `docs/images/category-goods.jpg` |
| ABOUT | `docs/images/daily-03-burgundy.jpg` 等の実写から選定 |
| DAILY 記事用 | `docs/images/daily-*.jpg` |

## 4. 仕様に対する未対応項目

- **NEW / LIMITED バッジ**: Dawn 標準の商品カードにはタグ連動バッジが無い。
  実装仕様では「必要に応じて」とあるため初期リリースでは見送り。
  必要になれば `snippets/card-product.liquid` に商品タグ判定を追加する。
- **ABOUT 画像**: `image` が未設定。Files アップロード後に選択が必要。
- **GUIDE の各行の本文**: `row_content` が空。送料/返品交換/FAQ の正式文言待ち（`docs/未確定事項.md`）。
