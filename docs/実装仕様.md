# 実装仕様

## 1. TOP
### HERO
- `02_実装用画像/01_TOP/hero_main_1600x900.jpg` を使用。
- CTAボタンなし。
- 必要な文字はHTML/CSSで重ねる。

### PICKUP
- スマホ2列。
- 2〜4商品を管理側で選択できる形が理想。
- 商品画像 / 商品名 / 価格 / 必要に応じてNEW・LIMITED。
- 「すべて見る」は下部中央。

### CATEGORY
- APPAREL / GOODS の2枚。
- APPAREL：`category_apparel_1200x800.jpg`
- GOODS：`category_goods_1200x800.jpg`
- APPAREL/GOODSの文字はHTML/CSS。
- CAP独立カテゴリは作らない。

### 新着
- 見出しは「新着」。
- スマホ2列。
- 商品を新しい順で表示。
- 「すべて見る」は下部中央。

### DAILY
- TOPでは最新4件程度、2列グリッド。
- 写真主体。
- Blog最新記事から取得。
- 「すべて見る」は下部中央。

### ABOUT
- 実写1枚 + 短い文章。
- 長文にしない。
- モック内の `ABOUT NASHE` 等の誤記は再現しない。リンク表記は `ABOUT` または日本語で自然に。

### SHOPPING GUIDE / FAQ
- 送料・お届け / 商品・交換 / よくある質問。
- TOPでは3項目のシンプルな導線。
- 詳細は1ページにまとめ、アコーディオンでOK。
- 問い合わせ導線は目立たせない。

### フッター
- SNSリンクは設定値化。
- 年号は固定で2024にせず、現在年を自動表示するか最新年に更新可能にする。

## 2. 商品一覧
- ALL / APPAREL / GOODS。
- スマホ2列。
- 商品画像 / 商品名 / 価格を基本。
- 複雑なフィルタ/絞り込み不要。
- カード内の余白をしっかり確保。

## 3. 商品詳細
必須項目のみ。
- 商品画像複数
- 商品名
- 価格
- カラー
- サイズ
- 在庫/SOLD OUT
- カートに入れる
- 商品説明
- サイズ・寸法
- 素材
- 配送・返品交換

関連商品は初期必須ではない。

## 4. DAILY
### 一覧
- 2列グリッド。
- 写真 / 日付 / 短いタイトル。

### 記事
- 写真1〜5枚 + 50〜200文字程度を想定。
- コメント機能なし。
- 問い合わせ導線なし。

Shopify Blogで実装。

## 5. ABOUT
- ブランド紹介 + 実写1〜2枚。
- シンプルでOK。

## 6. SHOPPING GUIDE / FAQ
- 1ページに集約。
- アコーディオンでOK。
- 管理側でテキスト編集可能にする。

## 7. カート
Shopify標準ベース。
- 商品
- 数量
- 小計
- 購入へ進む

初期はアップセル不要。

## 8. モバイルUI
- 基準幅：375〜390pxで確認。
- 左右余白：20px前後。
- セクション間：72〜96px目安。
- カード間：12〜16px。
- 本文：15〜16px基準。
- タップ領域：44px以上。
- 水平スクロールを発生させない。
- 画像アスペクト比を崩さない。
- `object-fit: cover / contain` を用途で使い分ける。

## 9. 画像/パフォーマンス
- HERO以外は基本lazy-load。
- Shopify image_url/image_tag等でレスポンシブ画像を出す。
- 画像を不必要に巨大表示しない。
- 商品写真のロゴ/文字/色を加工で変えない。

## 10. 実装しないもの
- 商品診断
- 高度な検索/複雑な絞り込み
- コメント機能
- 独自会員機能
- CAP独立カテゴリ
- 過剰なアニメーション
- 目立つ問い合わせ導線
- 商品画像のAI生成/描き直し
