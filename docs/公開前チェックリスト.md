# 公開前チェックリスト（管理画面作業）

テーマ側の実装は完了している。以下はすべて Shopify 管理画面での操作。
上から順にやると手戻りが少ない。

---

## 1. メニューの整理

販売チャネル → オンラインストア → **ナビゲーション**

### メインメニュー
Home / Catalog / Contact を削除し、以下に差し替える。

| 名前 | リンク先 |
|---|---|
| APPAREL | コレクション → APPAREL |
| GOODS | コレクション → GOODS |
| DAILY | ブログ → DAILY |
| ABOUT | ページ → ABOUT |

※ DAILY は「3. ブログ作成」の後でないと選べない。先に3をやってもよい。

### フッターメニュー（ハンドル `footer`）
Search を削除し、以下にする。

| 名前 | リンク先 |
|---|---|
| ABOUT | ページ → ABOUT |
| FAQ | ページ → FAQ |

プライバシーポリシー等はフッターに自動表示されるため、メニューに入れない。

**メインメニューから Catalog を削除したら教えてください。**
テーマ側に入れている「Catalog → Collection」の表示置換
（`snippets/hrh-menu-label.liquid`）が不要になるので外します。

## 2. ページ本文

販売チャネル → オンラインストア → **ページ**

- **ABOUT**（`about`）… 現在「テスト」のまま。ブランド紹介を入れる
- **FAQ**（`faq`）… 送料・お届け / 商品・交換 / よくある質問 の3項目

どちらも **公開状況を「公開」** にすること（非公開だと404になる）。

## 3. ブログ `daily` の作成

販売チャネル → オンラインストア → ブログ記事 → **ブログを管理する** → ブログを追加

- タイトル `DAILY` / ハンドルが `daily` になることを確認
- **記事を1本以上公開する。** 記事が0件だとTOPのDAILYセクションは表示されない
- 画像は `docs/images/daily-*.jpg` の4枚が使える
- 記事の想定: 写真1〜5枚 + 50〜200文字（`docs/実装仕様.md` 4.DAILY）

## 4. ポリシーの登録

設定 → **ポリシー**

**特定商取引法に基づく表記は「ページ」ではなくポリシーとして登録する。**
設定 → ポリシー の **「法的通知（Legal notice）」** セクションに入力する。
Shopify が日本向けのテンプレートを用意している。

| ポリシー | 入力場所 | 必須度 |
|---|---|---|
| 特定商取引法に基づく表記 | ポリシー → 法的通知 | **必須**（日本でShopifyペイメントを使う場合の要件） |
| プライバシーポリシー | ポリシー | 必須 |
| 返金ポリシー | ポリシー | 必須 |
| 配送ポリシー | ポリシー | 推奨 |

フッターへのリンク表示はテーマ側で有効化済み（`show_policy: true`）なので、
登録すれば自動で出る。

出典: https://help.shopify.com/en/manual/intro-to-shopify/initial-setup/sell-in-japan/japan-checkout-page

### 特定商取引法に基づく表記に必要な項目
通信販売の場合、おおむね以下を記載する。

- 販売業者名
- 運営統括責任者名
- 所在地
- 電話番号
- メールアドレス
- 販売価格（税込表示）
- 商品代金以外に必要な費用（送料・手数料）
- 代金の支払方法と支払時期
- 商品の引渡時期
- 返品・交換の条件と送料負担

## 5. 配送料金

設定 → **配送と配達** → 配送料金

### ヤマト運輸 関東発の実費（税込）

HTMLを直接パースして確認した確定値。

| サイズ | 同一都道府県内 | 北海道 | 北東北 | 南東北〜中部 | 関西 | 中国・四国 | 九州 | 沖縄 |
|---|---|---|---|---|---|---|---|---|
| 宅急便コンパクト | ー | 870 | 710 | 650 | 710 | 760 | 870 | 870 |
| 60 | 790 | 1,460 | 1,060 | 940 | 1,060 | 1,190 | 1,460 | 1,460 |
| 80 | 1,090 | 1,740 | 1,350 | 1,230 | 1,350 | 1,480 | 1,740 | 2,070 |

出典: https://www.kuronekoyamato.co.jp/ytc/search/estimate/ichiran.html

**60サイズなら北海道・九州・沖縄がすべて1,460円で同額**のため、
地域別にする場合も2ゾーンで足りる。

### 設定案

| 案 | 内容 |
|---|---|
| A. 全国一律 | **1,500円**。60サイズなら全国で赤字にならない |
| B. 地域別2ゾーン | 本州・四国 **1,200円** / 北海道・九州・沖縄 **1,500円** |
| C. 送料無料 | 商品価格への転嫁が前提。沖縄80サイズで2,070円の負担 |

いずれも**60サイズ想定**。80サイズになると沖縄のみ2,070円で足が出る。
梱包資材費は別途100〜200円程度を見込むこと。

### 送料無料ライン
Shopify の標準機能で、配送エリアごとに「注文金額に基づく条件」を付けられる。
アプリ不要。エリアごとに2行（0〜9,999円は有料 / 10,000円以上は0円）設定するだけ。

出典: https://help.shopify.com/en/manual/fulfillment/setup/shipping-rates/setting-up-shipping-rates

10,000円ラインの根拠: キャップ8,800円・トート5,500円のため、
キャップ1点では届かず、もう1点足すと超える。客単価を押し上げやすい。

### 宅急便コンパクト
専用BOXに入れば **650〜870円** で済む。トートバッグは薄手のため入る可能性がある。
キャップは厚みがあるため要検証。使えるなら送料を大幅に下げられる。

## 5-2. 独自ドメイン

設定 → **ドメイン**

`*.myshopify.com` のままでも公開はできるが、信頼性の面で独自ドメインを推奨。
特商法表記・FAQに載せるメールアドレスの形にも影響するため、**先に決めること**。

### メールアドレスの扱い
Shopify は**メール転送のみ提供し、メールホスティングは提供しない**。

- `info@（独自ドメイン）` を作り、株式会社アルヒノの実務アドレスへ**転送**できる
- ただし**そのアドレスから送信はできない**。返信すると転送先のアドレスが相手に見える
- ブランドのアドレスから送受信したい場合は、Google Workspace や Zoho Mail など
  外部のメールホスティングが別途必要

出典: https://help.shopify.com/ja/manual/online-store/domains/email-forwarding-and-hosting/email-forwarding

### 選択肢
| 案 | 内容 | 向き不向き |
|---|---|---|
| A | 独自ドメイン + Shopifyのメール転送 | 受信だけでよいなら最小コスト。返信時に転送先が露出 |
| B | 独自ドメイン + 外部メールホスティング | ブランドのアドレスで送受信できる。費用がかかる |
| C | 株式会社アルヒノのドメインのアドレス | すぐ使える。ブランド感は落ちる |
| D | Gmail（`honeyrosiehouse@gmail.com`）| **暫定採用**。費用ゼロで即日。送受信とも可 |

D案の注意:
- 特商法上、フリーメールでも問題ない（ドメインの指定はない）
- ただしEC事業者としての信頼感は独自ドメインに劣る
- 株式会社アルヒノと共有するなら、Gmailのアクセス委任機能を使うか、
  運用ルールを決めておくこと
- 独自ドメインへ移行する際は、**特商法表記とFAQの両方**を直すこと
