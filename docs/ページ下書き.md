# FAQ

ページタイトル: `FAQ` / ハンドル: `faq`

Shopify のページ編集画面で「HTMLを表示」に切り替えて、以下を貼り付ける。

## 貼り付け用HTML

```html
<h2>送料・お届けについて</h2>

<h3>送料はいくらですか？</h3>
<p>お届け先の地域により異なります。</p>
<ul>
  <li>本州・四国：1,200円（税込）</li>
  <li>北海道・九州・沖縄：1,500円（税込）</li>
</ul>

<h3>注文からどのくらいで届きますか？</h3>
<p>配送のご依頼を受けてから7日以内に発送いたします。配送状況により、お届けまでにお時間をいただく場合がございます。</p>

<h3>発送後に荷物の追跡はできますか？</h3>
<p>発送完了後、追跡番号をメールでお知らせします。</p>

<h3>日時指定はできますか？</h3>
<p>申し訳ございませんが、配送日時のご指定は承っておりません。</p>

<h2>商品・交換について</h2>

<h3>返品・交換はできますか？</h3>
<p>商品に欠陥がある場合を除き、返品には応じかねます。あらかじめご了承ください。</p>
<p>商品の品質には万全を期しておりますが、万一不良品や誤配送があった場合は、商品到着後7日以内にご連絡ください。送料当店負担にて交換または返金いたします。</p>

<h3>サイズが合わなかった場合は？</h3>
<p>お客様都合による返品・交換は承っておりません。サイズは商品ページの記載をご確認のうえ、ご注文ください。</p>

<h3>在庫切れの商品は再入荷しますか？</h3>
<p>再入荷の予定は商品によって異なります。決まり次第、Instagram でお知らせします。</p>

<h2>よくあるご質問</h2>

<h3>商品の素材を教えてください</h3>
<p>オリジナルトートバッグ、HONEY ROSIE HOUSE CAP ともに綿100%です。キャップはワンサイズで、内周48cm〜64cmの範囲で調節できます。</p>

<h3>ラッピングはできますか？</h3>
<p>申し訳ございませんが、ギフト用のラッピングは承っておりません。</p>

<h3>支払い方法は何がありますか？</h3>
<p>クレジットカード（Visa / Mastercard / JCB / American Express / Diners Club / Discover）、Apple Pay、Google Pay、Shop Pay をご利用いただけます。クレジットカードはご注文時にお支払いが確定します。実際のご請求日は、ご利用のカード会社の締め日・支払日によります。</p>

<h3>領収書は発行できますか？</h3>
<p>クレジットカード決済のため、当店では領収書を発行しておりません。ご注文時にお送りするご注文確認メール、またはご利用のカード会社の明細をもって領収書に代えさせていただきます。</p>

<h3>問い合わせはどこからできますか？</h3>
<p>Instagram のダイレクトメッセージ、または info@honeyrosiehouse.com までご連絡ください。受付時間は平日 11:00〜17:00（土日祝を除く）です。</p>
```

---

## 補足

- 固定仕様の「問い合わせ導線は目立たせない」に沿い、問い合わせ先はFAQの最後に控えめに置いている
- 送料・返品条件は特定商取引法に基づく表記とも整合させること。
  FAQとポリシーで内容が食い違うと問題になる
- 素材・サイズの記述は `docs/実装メモ.md` の商品マスタに基づく（綿100%、内周48〜64cm）
