# ABOUT

ページタイトル: `ABOUT` / ハンドル: `about`

## 貼り付け用テキスト

服を通して、心がほころぶ。
そんな時間を届けることが、私たちの役割だと信じています。

HONEY ROSIE HOUSE は、ファッションを通して、日常に小さなアクセントとハッピーを届けるブランドです。

特別な日のための服ではなく、なんでもない一日を少しだけ上向きにする服を。
手に取った人が、鏡の前でふっと笑顔になる。そんな瞬間を増やしたいと考えています。

アートワークはすべて自分たちの手で描いています。
量産されたものにはない、少しいびつで、少し過剰な愛着。
それがこのブランドの手触りです。

[要確認] ここに立ち上げの経緯や、つくり手の言葉を1〜2段落足すと厚みが出る。

## 補足

- 固定仕様の「問い合わせ導線は目立たせない」に沿い、問い合わせ先はFAQの最後に控えめに置いている
- 送料・返品条件は特定商取引法に基づく表記とも整合させること。
  FAQとポリシーで内容が食い違うと問題になる
- 素材・サイズの記述は `docs/実装メモ.md` の商品マスタに基づく（綿100%、内周48〜64cm）
